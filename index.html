Install Digital Songbook

Install this song catalog for an app-like window and offline browsing after the first successful load.

Chrome on Windows
Use the install icon at the right of the address bar, or open the three-dot menu and choose Cast, save, and share → Install page as app (wording may vary by Chrome version).

Chrome on Android
Open the site in Chrome, tap the three-dot menu, then choose Install app or Add to Home screen.

Safari on iPhone/iPad
Tap Share, then Add to Home Screen.

Installation requires the site to be served from HTTPS or localhost. A page opened directly using a file:// address is not an installable PWA.
